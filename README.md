### 🚧 What I've built

**[AniMatch](https://github.com/Blue-kaiCodes/AniMatch)** 🎌  
A full-stack anime recommendation and social platform. Built a content-based recommender from scratch using TF-IDF and cosine similarity to match users to titles by genre, synopsis, and studio, with graded match percentages instead of a generic "you might like." Also has an AI chat companion (Gemini-powered) for natural-language recommendations, a drag-and-drop Kanban watch board, live data pulled from the AniList GraphQL and Jikan/MyAnimeList APIs, and a full auth + profile system. Deployed and live.

`React 19` `TypeScript` `Node.js/Express` `Vite` `Tailwind CSS` `TF-IDF / Cosine Similarity` `Gemini API`

**[Railway Block Planner](https://github.com/Blue-kaiCodes/Railway-block-planner)** — Smart India Hackathon 2026  
Constraint-optimization system that automates maintenance block scheduling for Indian Railways. Uses Google OR-Tools CP-SAT to guarantee zero collisions between train movements and maintenance blocks, re-optimizes live on emergency defects, and explains every scheduling decision in plain English.

`Python` `FastAPI` `OR-Tools` `Pydantic`

**[ProcureIQ](https://github.com/Blue-kaiCodes/ProcureIQ)**  
Enterprise procurement platform with live bi-directional Odoo ERP sync, automated branded PO generation with vendor email dispatch, and full audit trails, plus a zero-config local setup so anyone can clone and run the full stack with demo data.

`React` `TypeScript` `Node.js/Express` `PostgreSQL`

**[ChronoShift](https://github.com/Blue-kaiCodes/ChronoShift)**  
Timezone and meeting planner for distributed teams — geographic overlap map, DST-aware availability engine, one-click calendar sync (Google/Outlook/.ics), and a Raycast-style command palette.

`React` `Vite` `Tailwind CSS` `Framer Motion`
